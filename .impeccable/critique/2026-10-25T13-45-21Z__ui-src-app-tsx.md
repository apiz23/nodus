## Design Specificity Verdict

**Category-interchangeable Notion shell, authored edges.**

The composition closely follows Notion: 240px gray sidebar, 680px editor measure, 40px title, 16px/24 body, quiet toolbar. Swap the “N” and it could be any Markdown notes app. Nodus-specific truth appears only at the edges: vault name/path, honest disconnected sync, stale-write protection, read-only database schemas, truthful save states.

Markdown identity, file provenance, wiki links, backlinks, and the link between the visual page and the actual `.md` file are absent from the point of work. The vault is 10px in the footer. The single biggest opportunity is making the file/vault the visible spine of the experience.

**Deterministic scan:** CLI scan of `ui/src` exited 0 with zero findings. Rendered scans at 1440x900 and 390x844 each found one `tiny-text` finding on the vault-path caption (10px desktop, 9.5px mobile). Detector was verified alive against fixture files. No false positives beyond the rule’s “body text” label being imprecise for a filesystem path caption.

**Visual overlays:** not user-visible. The harness desktop browser was disconnected. Injection was verified in headless Chrome, the live server ran on port 8400, and the overlay flagged the vault-path caption. Server was stopped and the port closed.

## Overall Impression

Quiet, credible writing surface with unusually honest save and sync states. The visual language succeeds as a Notion facsimile, but the product’s own differentiators are peripheral, dark mode breaks the writing canvas, and the highest-stakes exit paths fall back to browser-native confirms.

## What's Working

1. **Truthful save and conflict states.** Saving/Saved/Unsaved/Not saved, `aria-live`, disabled Save when clean. In a local-first product, data trust is the product.
2. **Honest sync posture.** `CloudOff` + “Not connected” in sidebar and Settings, detail on demand. No fake cloud affordances.
3. **Delete confirmation with real context.** Title, exact path, irreversibility warning, Cancel focused by default.

Honorable mention: Ctrl+K/N/S, tree arrow navigation, Escape-to-clear search, reduced-motion support.

## Cognitive Load

## Priority Issues

### [P1] Dark mode turns the editor body into a form field
**What:** `Textarea` base `dark:bg-input/30` wins over the editor’s `bg-transparent`; computed dark background is `oklab(0.348457 … / 0.3)` over `#191919`, producing a visible slab across the full 680x405 body.
**Why it matters:** The core writing surface looks like an input widget in half the theme matrix and contradicts the quiet-page composition.
**Fix:** Use a bare editor textarea primitive with no background, border, or ring in both themes. Replace the box outline with a caret and a subtle canvas-safe focus cue.
**Suggested command:** `$impeccable polish`

### [P1] Unsaved-work handoff only offers discard
**What:** Six paths use native `window.confirm('Discard unsaved changes…')`: vault switch, vault path open, note switch, create note, reload, rename. Stale-write recovery only offers Reload, which discards the local draft.
**Why it matters:** Highest-stakes moment in a local-first product; one misplaced OK erases work and browser chrome breaks the visual system.
**Fix:** One custom UnsavedChangesDialog with Save and continue / Discard / Cancel. For conflicts, offer Reload (discard mine) and Save as conflict copy with path and timestamp. Keep beforeunload as last resort.
**Suggested command:** `$impeccable harden`

### [P1] Notes/pages terminology and disappearing page tree split the model
**What:** Same object called note and page across labels. Title and filename are separate but unexplained. Breadcrumb segments look interactive but are static. Page tree unmounts on Databases/Settings, leaving the sidebar mostly empty.
**Why it matters:** Users cannot form a stable mental model; Notion-trained users expect title and filename to relate; half the app feels unfinished.
**Fix:** Pick one term. Add a file chip under the title (path, Markdown, reveal). Make title/path relationship explicit. Keep the tree mounted across views or add a clear Back to notes action.
**Suggested command:** `$impeccable clarify`

### [P1] Keyboard and screen-reader navigation does not scale
**What:** Notes view has zero headings; title is an input. Every tree item is in the tab order; 17 Tab presses reach the title with five notes. Mobile drawer has no focus trap, no Escape close, and the hamburger lacks `aria-expanded`/`aria-controls`. Page-info tooltip lays UUID and SHA-256 side by side and clips.
**Why it matters:** Screen-reader users cannot navigate by heading; large vaults become dozens or hundreds of tab stops; mobile focus can escape behind the drawer.
**Fix:** Real `h1` for the page title. Roving tabindex in the tree. Skip link to the editor. Shortcut/help overlay. Focus-trapped drawer with Escape and expanded state. Stack tooltip fields with `break-all`.
**Suggested command:** `$impeccable harden`

### [P1] A vault failure is a terminal dead end
**What:** Status failure renders a full-screen error with `NODUS_VAULT=... pnpm dev` and one Try again button; Settings and folder picker are unreachable.
**Why it matters:** Local-first users move folders. A moved vault makes the app unusable without a terminal.
**Fix:** Add Choose another folder and Open a folder path using existing pickVault/openVault. Add copy path and troubleshooting link; collapse the command for developers.
**Suggested command:** `$impeccable harden`

## Persona Red Flags

**Alex (Power User):** 17 Tab presses to the title. Palette cannot Save/Reload/Rename/Delete/Focus. Ctrl+K blurs the active field and does not restore the caret. Focus mode has no keyboard exit. No recent notes, favorites, bulk actions, or resizable sidebar.

**Sam (Accessibility-Dependent):** Zero headings on notes view. Tree uses `role="tree"` but all items are tab stops, no roving tabindex or `aria-activedescendant`. Dark textarea is a boxed slab; light focus cue exists but is a thin border. Mobile drawer does not trap focus or close on Escape. Vault path is 9.5–10px.

**Riley (Stress Tester):** Duplicate titles are indistinguishable; only native title tooltip reveals path. Empty title returns raw `title must not be empty` and the 200-character limit is undisclosed. Stale-write Reload discards local edits. Page-info tooltip wraps and clips. A 1000-note vault renders every node and tab stop.
