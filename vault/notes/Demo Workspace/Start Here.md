# Start Here

This is a **fictional demo workspace** for exploring Nodus. It is intentionally full of linked notes, projects, tasks, meetings, reference material, and structured database rows. Everything here is safe to edit or delete; the names, emails, and URLs are invented.

## Suggested tour

1. Start with the project overviews: [[Atlas Onboarding Refresh]], [[Beacon Mobile Companion]], [[Cedar Knowledge Graph]], and [[Dune Content Engine]].
2. Open **Databases** in the sidebar. The demo databases are prefixed with **Demo ·**.
3. Try the saved views: **All Tasks**, **Task Board**, **Task Calendar**, **Editorial Calendar**, and **Active Projects**.
4. Follow a few wiki links back into task, meeting, and people notes.

## The workspace map

- **Areas:** [[Product Studio]] and [[Research Lab]]
- **Projects:** four active or recently active workstreams
- **Tasks:** a working backlog with owners, dates, estimates, and completion state
- **Meetings:** five decision records with action links
- **Resources:** reading material and a plain Markdown scratchpad
- **People:** fictional team profiles for Maya, Noah, Priya, Élodie, and Kenji
- **Goals:** two measurable outcomes for the quarter
- **Content Calendar:** four editorial entries across several weeks
- **Templates:** reusable starting points
- **Archive:** one closed retrospective

## How the structured data works

The first column in every database is the note title; the other columns are typed properties stored in each note's `nodus_data` frontmatter. Select values point at stable option UUIDs. Wiki links are ordinary Markdown and are not relation properties.

## Edge cases included

The demo deliberately includes a long task title, Unicode names, empty optional text, missing optional dates, false checkboxes, a zero estimate and rating, a note without frontmatter, and a nine-option Channel select. No malformed fixtures are installed in this vault.

## Fictional data notice

All people, emails, projects, URLs, and results are invented for demonstration. Do not treat anything here as a real business record.
