# Cedar Knowledge Graph

**Status:** Active · **Owner:** [[Priya Raman]] · **Priority:** Urgent

Cedar explores how a Markdown workspace can make connection quality visible without turning into a graph-shaped screensaver. The demo focuses on link hygiene, backlink coverage, and accessible views.

## Outcomes

- Make unresolved and ambiguous links easy to find.
- Keep the graph explainable from ordinary Markdown.
- Improve keyboard access to saved views.
