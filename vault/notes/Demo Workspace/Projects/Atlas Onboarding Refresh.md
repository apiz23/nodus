# Atlas Onboarding Refresh

**Status:** Active · **Owner:** [[Maya Chen]] · **Priority:** High

Atlas is a fictional onboarding refresh for a small local-first product. The goal is to help a new user reach a first meaningful action without a tour-heavy setup flow.

## Outcomes

- Reduce the setup path to three visible steps.
- Make the first saved item feel like progress, not configuration.
- Measure activation with a clear, reviewable metric.

## Work in flight

- [[Define onboarding success metrics]] defines the success measure.
- [[Draft activation survey]] gives new users a way to describe friction.
- [[Build onboarding checklist prototype]] is the current prototype.
