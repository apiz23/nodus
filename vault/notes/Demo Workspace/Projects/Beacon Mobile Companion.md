# Beacon Mobile Companion

**Status:** Planning · **Owner:** [[Noah Williams]] · **Priority:** Medium

Beacon is a small mobile companion concept for capturing a thought before it disappears. It is deliberately limited: capture, link, and save for later.

## Questions

- Can the capture flow work offline without a sync decision?
- What is the smallest useful navigation model?
